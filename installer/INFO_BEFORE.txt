DESERTLINK v1.2

This installer installs only the DesertLink desktop companion.
It does not modify Crimson Desert and does not install ASI plugins automatically.

Before using teleport features, install these game-side requirements manually:

1. A working ASI loader for Crimson Desert
2. CrimsonDesertTelemetry.asi
3. DesertLinkCore.asi (included with the DesertLink release)

Copy DesertLinkCore.asi to the same ASI folder as CrimsonDesertTelemetry.asi.

The installer performs no runtime downloads and uses no PowerShell.
The Electron runtime is bundled into the installer during the release build.
