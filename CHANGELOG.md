# Changelog

## 1.2.0

- Updated Crimson Desert compatibility to 2.02.00 / executable 1.0.0.2850.
- Added fully remappable keyboard and map mouse bindings.
- Added duplicate and unavailable shortcut validation with safe rollback.
- Added Reset Defaults, Esc cancel, and Backspace/Delete unbind behavior.
- Added Game Focus Mode.
- Added persistent waypoint map markers and waypoint renaming.
- Added persistent panel size/position and a resizable control panel.
- Added dynamic control hints that reflect current bindings.
- Preserved App Mode, Overlay Mode, live telemetry, follow mode, map teleport, return teleport, Y control, and persistent login.
